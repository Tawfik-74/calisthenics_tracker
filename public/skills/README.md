# Skill photos

`SkillArt` (`src/features/plan/ui/SkillArt.tsx`) shows one image per skill in the
skill roadmap, the skill picker, and the "Skill lore" card on a generated plan.

Drop a photo here for each skill using the **exact** filename below. Anything
missing falls back to the built-in SVG silhouette automatically — no code change
needed. `.jpg` is expected; to use another format, update the `PHOTOS` map in
`SkillArt.tsx`.

| File | Skill | Pose |
| --- | --- | --- |
| `handstand.jpg` | Handstand | Freestanding handstand |
| `muscle_up.jpg` | Muscle-Up | Top of the bar transition / straight-bar dip |
| `pistol_squat.jpg` | Pistol Squat | Full-depth single-leg squat, free leg forward |
| `planche.jpg` | Planche | Straight body parallel to the ground on the hands |
| `front_lever.jpg` | Front Lever | Horizontal hang under a bar, facing up |
| `human_flag.jpg` | Human Flag | Horizontal hold on a vertical pole |
| `dragon_flag.jpg` | Dragon Flag | Rigid straight body pivoting at the shoulders on a bench |

Recommended: ~1200×900 (4:3), landscape, subject centred, < 250 KB each
(`.webp` is smaller if you switch the extension in `PHOTOS`).
